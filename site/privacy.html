Privacy Policy

Effective July 14, 2026

Midnight SSH is a local-first SSH and server-operations application for macOS, iPhone, and iPad. This policy explains what the app processes and when data leaves your device.

Data stored on your device

  • Saved host profiles, folders, preferences, runbooks, and local operational history.
  • Passwords, tokens, key passphrases, and key-encryption secrets in Apple Keychain using device-only accessibility where supported. Imported private keys are encrypted on device.
  • Host keys in the app's known-hosts store so changed server identities fail closed.

Midnight SSH does not operate an account service or upload this data to a developer-controlled server.

Direct server connections

When you connect, your device communicates directly with the SSH, SFTP, database, or related endpoint you selected. Server addresses, commands, file contents, query text, and command results are processed to provide the requested feature.

Optional IP geolocation

Connection Map is disabled until you opt in. If enabled, the app sends public source IP addresses found in connection and firewall data to ipwho.is to obtain approximate geographic coordinates. Private, loopback, link-local, and reserved addresses are not useful for this service. You can disable geolocation in the app's privacy settings or system defaults. The provider's own privacy terms apply to its processing.

Purchases and updates

Apple processes App Store purchases and provides signed transaction status to the app. Developer ID Mac builds may contact GitHub Releases through Sparkle to check for updates; GitHub receives normal web-request metadata such as your IP address and user agent.

Diagnostics

Anonymous usage diagnostics are off by default. Unified log collection for exported support bundles is also off by default. A diagnostics bundle is created only when you request it and remains local until you choose to share it. Review it before sending because operational errors can contain infrastructure details despite automatic redaction.

Analytics, advertising, and tracking

Midnight SSH does not include advertising SDKs, does not track you across apps or websites, and does not sell personal data.

iCloud

iCloud profile synchronization is not enabled in current release builds. If introduced later, the app will describe the synchronized fields before enabling it; credentials and private keys will remain excluded.

Retention and deletion

Delete profiles, runbooks, and history in the app. Delete the app to remove its container data; Apple Keychain may retain items until explicitly removed or the device is erased. Data held by servers you connect to, Apple, GitHub, or ipwho.is is governed by those providers.

Children

Midnight SSH is a professional developer utility and is not directed to children.

Changes and contact

Material changes will be posted here with a revised effective date. Questions: midnightssh@proton.me. Security reports should use GitHub private vulnerability reporting.

Support

Midnight SSH currently supports macOS 13 or later and iOS/iPadOS 17 or later. Mobile builds are beta software.

Before contacting support

  1. Confirm the host is reachable from the same network or VPN.
  2. Verify the host name, port, username, and authentication method.
  3. Review any host-key warning carefully; do not bypass an unexpected key change.
  4. Retry with a standard terminal SSH client to distinguish server configuration from app behavior.

Local network access

On iPhone or iPad, LAN hosts may require Local Network permission. Open Settings → Privacy & Security → Local Network and enable Midnight SSH if access was previously denied.

Background sessions

iOS and iPadOS may suspend network sockets after the app leaves the foreground. Use tmux or screen on the server for long-running terminal work. The app does not claim uninterrupted background SSH execution.

Send a useful report

Email midnightssh@proton.me with the platform and OS version, app version, steps to reproduce, and the exact non-secret error. Never send passwords, private keys, tokens, or unreviewed diagnostics. For security issues, use private vulnerability reporting.

Open source and issue tracking

Source, release notes, and public bug reports are available at github.com/asmuelle/agent-ssh.
